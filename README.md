# 💳 Sistema Bancário Web

Sistema de gerenciamento de contas bancárias desenvolvido com HTML, CSS e JavaScript puro, com foco em uma interface moderna, intuitiva e responsiva.

## 🚀 Demonstração

Acesse a aplicação online:

👉 https://dioguis.github.io/sistema_bancario_dioguis/

## 📋 Funcionalidades

* Cadastro de clientes
* Consulta de contas por número
* Atualização de saldo
* Encerramento de contas
* Listagem de clientes
* Dashboard com estatísticas
* Busca de clientes
* Persistência de dados utilizando LocalStorage
* Interface responsiva para desktop e dispositivos móveis
* Tema moderno inspirado em sistemas bancários digitais

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* LocalStorage

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos de desenvolvimento web front-end, manipulação do DOM, armazenamento local de dados e construção de interfaces responsivas utilizando tecnologias fundamentais da web.

Além disso, o sistema simula operações básicas de gerenciamento bancário, permitindo o cadastro e administração de contas de forma simples e intuitiva.

## 💻 Como Executar Localmente

1. Clone este repositório:

```bash
git clone https://github.com/Dioguis/sistema_bancario_dioguis.git
```

2. Acesse a pasta do projeto:

```bash
cd sistema_bancario_dioguis
```
